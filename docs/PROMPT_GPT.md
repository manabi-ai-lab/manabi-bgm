# ChatGPT（じぴ）への指示書 — 放課後トークルーム 制作情報の回収

あっきーがChatGPTのチャットに**そのまま貼る**ためのプロンプト。
目的：ChatGPT側にしか残っていない制作情報を回収して、このリポジトリの空欄を埋める。

回収した回答は、そのままClaudeに渡せば `SUNO.md` などへ転記します。

---

## 使い方

1. 下の「ここから」〜「ここまで」をコピーする
2. 放課後トークルームの制作をやったChatGPTのチャット（またはプロジェクト）に貼る
3. 返ってきたMarkdownを、そのままClaudeに貼り付けて「これで空欄埋めて」と言う

---

## 回収後にやること（Claude側）

| 回答の項目 | 転記先 |
| --- | --- |
| 1. Suno制作情報 | `tracks/after-school-talk-room/SUNO.md` の未記入欄 |
| 2. 1時間化の方法 | 同上「1時間化の方法」 |
| 3. 映像・サムネイル | `tracks/after-school-talk-room/README.md` / `VIDEO_SPEC.md` |
| 4. 書き出し・受け渡し | `VIDEO_SPEC.md` / `STATUS.md` のログ |
| 5. その他 | `STATUS.md` / `docs/PLAYBOOK.md` の「落とし穴」 |

「不明」のままの項目は、SUNO.md に「不明（ChatGPT側にも記録なし）」と書いて確定させる。
**空欄を推測で埋めることだけは、どちらのAIもやらない。**

## 注意

- ChatGPTがサムネイル画像を出してきた場合：**Driveにある元画像（265,782バイト）と同じものか確認する。** 違うファイルなら、Driveの方を正とする
- ChatGPTがMP4を「再書き出しして渡そうか」と提案してきても**断る**。配布に使えるのはSHA-256が `118de0f3…` に一致する高画質版だけ
- パスワードやログイン情報は、どちらの方向にも渡さない
