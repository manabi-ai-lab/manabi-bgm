## 設計（30秒・縦9:16）

映像：10秒ループ×3周。画面は縦向きに中央配置し、上下は**ぼかし背景**（CapCutの「背景」機能）。
音声：v2 の頭から30秒。**末尾0.3秒だけフェードアウト**（ループ再生時の違和感防止）。

| 時間 | 画面テキスト（テロップ） | ねらい |
| --- | --- | --- |
| 0.0–2.5秒 | **雑談配信のBGM、決まってる？** | 問いかけフック |
| 2.5–8秒 | 「放課後の教室」みたいな明るいフリーBGM、作りました | 曲名の世界観＋検索語（明るいフリーBGM） |
| 8–14秒 | 🎧 声とぶつからない音だけで作ってます | 一番の売り |
| 14–20秒 | ✅ 1時間ループ ✅ 収益化配信もOK ✅ 無料 | 利用条件を3点で |
| 20–27秒 | 使い方：概要欄のクレジットをコピペするだけ | ハードルを下げる |
| 27–30秒 | フル（1時間）は本編へ🎧 → コメント欄 | 導線。テキストは早めに消して**ループの継ぎ目を自然に** |

テロップの色はサムネイルと同系（白＋ピンク系縁取り）。フォントはCapCutの丸ゴシック系。

## スマホでの作り方（CapCut・約15分）

1. 上の**10秒ループ動画とMP3をスマホに保存**（Driveアプリ→各リンク→ダウンロード）
2. CapCutで新規プロジェクト → 10秒動画を選ぶ
3. 動画を選択 → **コピー**を2回 → 10秒×3＝30秒にする
4. 画面比率：**9:16** → 動画を中央に → **背景 → ぼかし**
5. **オーディオ → 楽曲 → 端末から** → MP3を追加 → 30秒でカット → 音量100%
6. 音声クリップ末尾に**フェードアウト0.3秒**
7. **テキスト**で上の表のテロップを6本入れる（表示時間も表のとおり）
8. 書き出し：**1080p / 30fps**
9. YouTubeアプリ →＋→ ショート動画としてアップロード（下の投稿文を使用）
10. TikTokにも同じ動画を投稿（下のTikTok用キャプションを使用）
